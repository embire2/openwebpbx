OUR REASON FOR BUILDING

Built for people.
Open to everyone.

We believe a great phone system should be within reach of every business, community and organization. OpenWeb PBX is a nonprofit, open-source project working to make that possible.

Our mission is simple: make business communications easier to use, freely available and owned by the people who depend on them. We build in public, share our progress honestly and welcome anyone who wants to help.

GOOD QUESTIONS

A few things
worth knowing.

Clear answers, before you get started.

Is OpenWeb PBX really free?+

Yes. OpenWeb PBX is a nonprofit, open-source project with no OpenWeb software license fee. You can inspect, host and customize the source under its licenses. Your server, phone numbers, calling provider and optional external services have their own costs.

Can I import my 3CX backup?+

The current importer has been verified against 3CX V20 Update 9 build 20.0.9.995. It restores supported settings and media and gives you a Restore Report for missing or unmapped items. Other native builds need validation. OpenWeb PBX does not yet offer complete 3CX feature parity, and the new Android app replaces the core calling workflow rather than every proprietary client feature.

Can I install it on Windows 10 or 11?+

The released full-server installer uses Windows Server components and has been tested on Windows Server 2025 with Desktop Experience. Dedicated Windows 10 and 11 server installers are still planned. You can use a browser on your PC to administer an existing PBX. The current Windows package also includes a WinUI manager; Windows 10/11 compatibility has not yet been qualified.

Is it ready for my business?+

Version 1.0.3 is an early, actively developed release. Installation, internal calling, callbacks and wake-up calls have been tested, and a controlled carrier call has completed. Qualify your own provider, Android handset, incoming calls and call flows before replacing a production phone system. Read the feature coverage for the full picture.

How can I help the project?+

Test a release, improve a guide, share a reproducible bug report or contribute code. Start with the public GitHub repository and the roadmap. Small improvements help more people make themselves at home.
