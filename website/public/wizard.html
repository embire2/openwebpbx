Where do I find my setup code?

For a Webhotel.cloud installation, open the new server's console or setup details. For another Debian installation, use the setup link displayed after installation. Keep that server running while you finish these steps.

Preparing your server

Keep your server running. We are preparing its address and secure connection.

  1. Account connected
  2. Server address created
  3. Server authorized
  4. Tenant address and secure connection checked

This can take a few minutes. You do not need to add DNS records or enter provider API credentials.

Taking longer than expected?

Make sure the server is still running and has internet access. If your hosting panel reports a blocked connection, use its support option. Your setup can safely retry without creating a second PBX.

Your PBX is ready

Your server is registered and its secure tenant address has been checked.

Open my PBX ↗

Sign in using the administrator account configured on your installed PBX. Your OpenWeb registration account manages server authorization.

OpenWeb PBX is a free, open-source project. Your calls and PBX data stay on your installed server.
