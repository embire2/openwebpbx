# Documentation images

`pbx-setup.png` is an unmodified screenshot of the OpenWeb PBX administration interface showing an empty setup workspace. It was captured during the project's browser checks and visually reviewed before publication. It contains no customer users, phone numbers, tenant identifiers, credentials, private logs or server addresses.

The screenshot illustrates the interface; it is not evidence that every feature in a particular release has been qualified. Use the release guides and feature-coverage record for that scope.
