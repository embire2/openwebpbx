# Standalone GitHub repository

Checked on 26 October 2026: `embire2/openwebpbx` is public and still belongs to the FusionPBX fork network. GitHub reports one child fork. Its reported repository size is 151,157 KiB.

[GitHub's detachment instructions](https://docs.github.com/en/pull-requests/how-tos/work-with-forks/detaching-a-fork) require a public fork below 1 GB with no child forks for the self-service option. They also warn that repository metadata can be lost. The existing child fork therefore needs GitHub's review before detachment can proceed safely.

OpenWebPBX's releases, update feeds, Actions configuration and qualification records depend on the existing repository. Keep its history, licence, copyright notices and upstream attribution. The README presents OpenWebPBX as its own project while acknowledging those origins. No repository deletion, recreation or detachment has been performed.

The owner can submit the following request through [GitHub Support](https://support.github.com/):

> Subject: Detach embire2/openwebpbx while preserving releases and repository identity
>
> I own the public repository https://github.com/embire2/openwebpbx, repository ID 1406074259. OpenWebPBX has developed independently and we want it to become a standalone repository, preserving the full Git history, licence and upstream attribution.
>
> GitHub currently reports one child fork, so the documented self-service detachment conditions are not met. Please advise whether you can detach the repository and handle its child fork without deleting or recreating our repository.
>
> Before making a change, please confirm its effect on our repository ID and URL, releases and download URLs, update feeds, Actions workflows/secrets/run history, issues, pull requests, stars, watchers and the child fork. Existing installations depend on those downloads and signed update feeds.
>
> Please provide the proposed preservation and recovery steps for review before performing the detachment.

This request is prepared and has not been sent. Detachment is separate from Windows release qualification.
