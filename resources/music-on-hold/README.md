# OpenWeb PBX hold music

**Lofi Beat Loop Schmoop** by **Seth_Makes_Sounds** is the bundled relaxed instrumental hold track. The creator publishes it under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/), allowing copying, adaptation, distribution and performance, including commercial use, without attribution being required.

Creator's source: https://freesound.org/people/Seth_Makes_Sounds/sounds/722425/

The source MP3 is the public high-quality full-length preview offered by Freesound. It is 135 seconds long. OpenWeb PBX converts that file to 16 kHz mono, 16-bit PCM WAV and normalizes loudness to -23 LUFS with a -3 dBTP ceiling for comfortable telephone playback. No speech, promotions or advertising have been added. The creator's name and source remain here as a courtesy and for provenance, with no endorsement implied.

`manifest.json` records the retrieval date, exact download URL, transformations and both file SHA-256 digests. Preserve this notice and manifest when redistributing the bundled files. The application code retains its separate original/AGPL licensing; this audio asset is CC0.

The operational installation and playback checks are documented in [docs/music-on-hold.md](../../docs/music-on-hold.md).
